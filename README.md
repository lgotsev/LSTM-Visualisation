# LSTM визуализация

Интерактивна визуализация на рекурентни невронни мрежи и LSTM за лекция (90 мин) и упражнение (90 мин). Всичко върви по една задача — оценка на тона на филмово ревю (IMDB), дума по дума — с реални обучени модели, чиито тегла са вградени в приложението.

## Секции

1. **Рекурентни мрежи** — MLP срещу RNN, embedding (дума → номер → вектор), сгъната и разгъната RNN, клетката на RNN дума по дума, рекурентна срещу рекурсивна.
2. **Затихващ градиент** — множител wₕ·γ на степен T, реалното влияние на думите в двата модела, „wonderful/terrible“ + неутрален пълнеж.
3. **LSTM** — конвейерната лента cₜ, интерактивна схема на клетката (всеки гейт е формален неврон), разходка по изречението, топлинна карта, експерименти със заключени гейтове.
4. **Сравнение (упражнение)** — синтетична задача „Запомни първия символ“, собствени изречения, брой параметри, GRU, задачи.

## Модели

| Модел | Embedding | Скрити единици | Точност (тест) | Параметри без embedding |
| --- | --- | --- | --- | --- |
| LSTM | 8 | 4 | 87.0% | 208 |
| RNN | 8 | 4 | 82.4% | 52 |

Речник от 5 000 думи. Плюс 10 синтетични модела (RNN-4 и LSTM-4 за N = 10, 20, 30, 50, 100). Теглата са в `src/model/weights.json`; приложението смята само forward pass в браузъра.

## Локално

Изисква Node.js 18+.

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # forward pass в JS срещу Python (до 3-тия знак) + синтетичните модели
npm run build
npm run check:layout # Playwright при 1280×720: няма застъпени числа и хоризонтален скрол на страницата
```

`check:layout` използва Playwright (`npm i -D playwright`, после `npx playwright install chromium`, или `PW_CHROMIUM=/път/до/chrome`). Скрийншотите отиват в `tests/screens/`.

## Деплой във Vercel

Като CNN и формалния неврон: Vercel разпознава Vite (`vercel.json`): build `npm run build`, output `dist`. След първото отваряне приложението работи без интернет (service worker).

## Самопроверка
